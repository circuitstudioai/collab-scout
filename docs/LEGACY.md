# Historical collaboration prototype

The repository originally hosted Collab Scout, a consumer-brand partnership finder. It is not the restaurant product being submitted. The old `lib/agent/` partnership orchestrator, generated drafts, brand seed data, app naming configuration and product-specific tests were removed. They remain recoverable in Git history. Shared Qloo transport utilities remain, but the active restaurant flow uses the direct authenticated GET reader and never a silent mock fallback.

The old `/scout/*` screens and partnership API are retired. Original source and product plans remain recoverable in Git history. The public internal planning upload was moved out of the application repository; it is not a product specification.

Current source of truth: `SCOUT_AGENT.md`, extending `RESTAURANT_EXPANSION.md`. Root README describes only the active restaurant product.
